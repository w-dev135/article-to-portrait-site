# Style: glass-editorial（编辑手记 Glass）

默认风格。暖纸底 + 玻璃 Hero + 方法钉住滚动。

## 色板
- 底：`#f4efe6` 暖纸；网格淡灰
- 字：近黑 `#1a1a1a`
- 点缀：克制 lime `#b8ff3c`（点、箭头，勿大面积）

## 字体节奏
- Hero 口号 / 大标题：衬线或带衬线感
- HUD / 坐标 / 标签：等宽或小写无衬线
- 正文：可读无衬线

## Hero
- 玻璃/气泡大字（WebGL 可；失败 SVG/CSS 回退）
- 顶底测量线、坐标 HUD 可选
- 三列 meta（学科 / 态度 / 简介）
- 底部大标题 + scroll 提示

## 作品 / 文章 / 方法
- 作品：错落或左右交替卡片，原生 video
- 文章：列表/表格风，悬停底色
- 方法：粘性大字 + 四步；滚动只换文案；侧边克制粒子

## 禁区
- 玻璃舞台禁止 `position:fixed` 盖住后续章
- 不堆酸性贴纸、强霓虹
- Lenis 下方法区用 JS 钉住

## 验收补充
- [ ] 强刷后 Hero 动效可见，滚到文章/方法不空白
- [ ] 方法卡滚动切换完整且不提前滑走
